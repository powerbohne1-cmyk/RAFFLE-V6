# V3 changes

- English-only Discord UI and messages.
- Raffle order is always Red → Gold → Purple → Blue.
- Loot is grouped under its class in that color order.
- Delete/remove loot items and loot classes from the Discord admin panel.
- Historical raffle records are preserved automatically when an item/class has already been used.
- Cooldown reset for one Discord player or all players.
- `/cooldown-reset player:@User` and `/cooldown-reset all:true`.
- Admin proxy entry flow: Active Raffle → Add Proxy → choose loot → enter proxy name.
- Proxy entries participate in draw and cooldown logic.
